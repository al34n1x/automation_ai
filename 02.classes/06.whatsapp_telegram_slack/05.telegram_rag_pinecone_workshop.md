# Lab: Agente con RAG en n8n usando Telegram y Pinecone

En este laboratorio vas a construir un agente básico en `n8n` que:

1. recibe preguntas desde `Telegram`
2. consulta una base vectorial en `Pinecone`
3. responde usando un `AI Agent`

## Objetivo

Al finalizar este lab, tendrás un workflow funcional llamado `Telegram RAG Agent` que responderá preguntas desde Telegram usando información ya cargada en Pinecone.

## Importante

En este laboratorio **no vas a cargar documentos** a Pinecone.

La base vectorial ya está provisionada y ya contiene información. Tu trabajo es construir únicamente el agente que consulta esa base.

## Requisitos

Antes de empezar, asegúrate de tener:

1. acceso a `n8n`
2. credencial de `Telegram` en n8n
3. credencial de `OpenAI` en n8n
4. credencial de `Pinecone` en n8n
5. nombre del `Index` de Pinecone
6. nombre del `Namespace` de Pinecone
7. el modelo de embeddings que corresponde a ese índice

## Regla clave

Debes usar el mismo modelo de embeddings que corresponde al índice provisionado.

No cambies el modelo por tu cuenta. Si no sabes cuál usar, pregunta al instructor.

---

## Resultado final esperado

Tu workflow debe quedar así:

```text
Telegram Trigger
   -> AI Agent
        -> OpenAI Chat Model
        -> Pinecone Vector Store
             -> Embeddings OpenAI
   -> Telegram
```

---

## Parte 1: Crear el bot de Telegram

Si ya tienes un bot creado, puedes pasar a la Parte 2.

### Paso 1. Crear el bot

1. Abre Telegram.
2. Busca `@BotFather`.
3. Envía `/start`.
4. Envía `/newbot`.
5. Elige:
   - un nombre para el bot
   - un username que termine en `bot`
6. Copia el token que te entrega BotFather.

### Paso 2. Crear la credencial en n8n

1. En n8n, abre `Credentials`.
2. Crea una credencial nueva de tipo `Telegram`.
3. Pega el token del bot.
4. Guarda la credencial.

---

## Parte 2: Crear el workflow

### Paso 1. Crear un workflow nuevo

1. Haz clic en `New Workflow`.
2. Guarda el workflow con el nombre:

```text
Telegram RAG Agent
```

---

## Parte 3: Agregar el trigger de Telegram

### Paso 1. Agregar `Telegram Trigger`

1. Agrega el nodo `Telegram Trigger`.
2. Selecciona tu credencial de Telegram.
3. En `Updates`, selecciona:

```text
Message
```

### Qué hace este nodo

Este nodo escucha los mensajes que llegan a tu bot de Telegram.

---

## Parte 4: Agregar el agente

### Paso 1. Agregar `AI Agent`

1. Agrega el nodo `AI Agent`.
2. Conéctalo después de `Telegram Trigger`.

### Paso 2. Configurar el texto de entrada

En el campo de input del agente, usa esta expresión:

```text
={{ $json.message.text }}
```

### Paso 3. Configurar el `System Message`

Pega este prompt:

```text
Eres un asistente del taller de n8n.

Tu trabajo es responder preguntas usando únicamente la información recuperada desde Pinecone.

Reglas:
- Usa la base vectorial como fuente de verdad.
- No inventes información.
- Si no encuentras la respuesta en la base, responde:
  "No tengo esa información dentro del material disponible."
- Responde siempre en español.
- Sé claro, breve y útil.
```

### Qué hace este nodo

Este nodo recibe la pregunta del usuario, decide cuándo usar herramientas y genera la respuesta final.

---

## Parte 5: Conectar el modelo de chat

### Paso 1. Agregar `OpenAI Chat Model`

1. Agrega el subnodo `OpenAI Chat Model` al `AI Agent`.
2. Selecciona tu credencial de OpenAI.
3. Elige un modelo disponible.

### Configuración sugerida

Usa un modelo rápido y económico.

Si ves un campo de temperatura, usa un valor bajo.

### Qué hace este nodo

Es el modelo que redacta la respuesta final del agente.

---

## Parte 6: Conectar Pinecone como herramienta

### Paso 1. Agregar `Pinecone Vector Store`

1. Agrega un nodo `Pinecone Vector Store`.
2. Conéctalo al conector de herramientas del `AI Agent`.

### Paso 2. Configurar el modo de operación

En `Operation Mode`, selecciona:

```text
Retrieve Documents (As Tool for AI Agent)
```

### Paso 3. Configurar Pinecone

Completa los campos así:

1. `Credentials`: tu credencial de Pinecone
2. `Pinecone Index`: el índice indicado por el instructor
3. `Pinecone Namespace`: el namespace indicado por el instructor
4. `Limit`: `4`

### Paso 4. Configurar nombre y descripción de la herramienta

Usa estos valores:

`Name`

```text
workshop_kb
```

`Description`

```text
Usa esta herramienta para responder preguntas sobre el contenido del taller de n8n, RAG, Telegram y Pinecone.
```

### Qué hace este nodo

Este nodo permite que el agente busque fragmentos relevantes dentro de Pinecone antes de responder.

---

## Parte 7: Conectar embeddings

### Paso 1. Agregar `Embeddings OpenAI`

1. Agrega un subnodo `Embeddings OpenAI` al `Pinecone Vector Store`.
2. Selecciona tu credencial de OpenAI.
3. Elige el mismo modelo de embeddings que corresponde al índice provisionado.

### Qué hace este nodo

Convierte la pregunta del usuario en un vector para poder buscar similitud semántica en Pinecone.

---

## Parte 8: Enviar la respuesta a Telegram

### Paso 1. Agregar el nodo `Telegram`

1. Agrega un nodo `Telegram`.
2. Selecciona la misma credencial del bot.
3. En la operación, elige:

```text
Send Message
```

### Paso 2. Configurar `Chat ID`

Usa esta expresión:

```text
={{ $('Telegram Trigger').item.json.message.chat.id }}
```

### Paso 3. Configurar `Text`

Usa esta expresión:

```text
={{ $json.output }}
```

### Paso 4. Conectar el flujo

Conecta la salida principal de `AI Agent` al nodo `Telegram`.

### Qué hace este nodo

Envía al usuario la respuesta generada por el agente.

---

## Parte 9: Guardar y activar

### Paso 1. Guardar el workflow

Guarda el workflow.

### Paso 2. Activarlo

Activa el workflow para que Telegram pueda enviar mensajes al trigger.

---

## Parte 10: Probar el agente

Abre Telegram y escribe a tu bot.

Prueba con preguntas como estas:

1. `¿Qué significa RAG?`
2. `¿Qué hace Pinecone en este flujo?`
3. `¿Qué nodo recibe los mensajes de Telegram?`
4. `¿Qué hace el AI Agent?`

## Qué deberías observar

1. El mensaje entra por `Telegram Trigger`.
2. El `AI Agent` procesa la pregunta.
3. El agente consulta Pinecone.
4. El bot responde en Telegram.

---

## Prueba de control

Haz una pregunta que probablemente no esté en la base de conocimiento.

Por ejemplo:

```text
¿Cuál es el precio del curso?
```

El agente debería responder algo parecido a:

```text
No tengo esa información dentro del material disponible.
```

Si el agente inventa una respuesta, revisa el prompt del sistema.

---

## Checklist final

Antes de terminar, verifica:

1. el workflow está guardado
2. el workflow está activo
3. Telegram Trigger recibe mensajes
4. AI Agent genera salida
5. Pinecone usa el índice correcto
6. Pinecone usa el namespace correcto
7. Embeddings OpenAI usa el modelo correcto
8. Telegram envía la respuesta final

---

## Troubleshooting

### Problema 1. No llega ningún mensaje desde Telegram

Revisa:

1. que el workflow esté activo
2. que la credencial de Telegram sea correcta
3. que el bot sea el correcto

### Problema 2. Telegram Trigger no funciona en self-hosted

Si n8n está autoalojado, revisa que la URL pública del webhook sea `HTTPS`.

### Problema 3. El agente responde que no sabe todo el tiempo

Revisa:

1. el índice
2. el namespace
3. el modelo de embeddings
4. que la base realmente tenga contenido cargado

### Problema 4. El agente responde cosas inventadas

Revisa:

1. el `System Message`
2. que Pinecone esté conectado como herramienta
3. que el agente esté usando la salida de Pinecone
